# 🏨 Hotel Management System

A Java-based Hotel Management System that allows managing guests, room bookings, and hotel services through a command-line interface. Designed for educational and practice purposes using object-oriented programming principles.

---

## 📦 Features

- Add, edit, and delete guest records
- Book and manage hotel rooms
- View available rooms and room details
- Generate basic invoices
- Console-based user interaction

---

## 🛠️ Technologies Used

- Java (JDK 8+)
- Object-Oriented Programming
- Command-line interface (CLI)
